# Portable-copy changes

Only `code_revision/rjobs.py` was edited from the retained source files: five references to the original `inst5` directory now point to this package's `code` directory; the CLI docstring now lists the four actual arguments. The model equations, fitted parameters, seeds and result records are unchanged.

`configs/legacy_final_battery.json` supplies explicit runtime overrides inferred from the original Methods and checked against the archived proportional-rule results; default values in legacy executables remain unchanged. New examples are subsets of the recorded tasks or reduced-budget execution checks.

The original hosted LLM adapter, server shell launchers, session replay helpers, duplicate executable snapshots, progress/error logs and superseded original figure sources are omitted. Their absence does not affect the eight revised figures or the supplied evaluation examples. Full historical source-data aggregation is not provided as one standalone script; the supplied source tables and raw task outputs are retained.
